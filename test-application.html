Заявка

Заполните заявку для получения доступа к тестированию знаний и опыта администрации Aress Family.

Не знаете, где найти Discord ID?
На телефоне:
Discord → ваш аватар → Настройки → Расширенные → включите «Режим разработчика» → откройте свой профиль → «Копировать ID пользователя».

На компьютере:
Discord → Настройки пользователя → Расширенные → включите «Режим разработчика» → нажмите ПКМ по своему имени или аватару → «Копировать ID пользователя».
Discord ID выглядит примерно так: 123456789012345678
⚠️ Перед прохождением теста рекомендуем внимательно изучить правила сервера.
