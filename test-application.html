01 — Заявка

Заполните заявку на получение доступа к тестированию знаний и опыта в администрации Aress Family.

Укажите именно Discord ID, а не никнейм.
Не знаете, где найти Discord ID?

На телефоне:
Discord → ваш аватар → Настройки → Расширенные → включите «Режим разработчика». После этого откройте свой профиль и выберите «Копировать ID пользователя».

На ПК:
Discord → Настройки пользователя → Расширенные → включите «Режим разработчика». Затем нажмите на свой аватар или имя и выберите «Копировать ID пользователя».

Discord ID — это длинная последовательность цифр.

⚠️ Перед прохождением теста рекомендуем внимательно изучить правила сервера.
